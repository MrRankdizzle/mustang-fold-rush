# Mustang Fold Rush

Code it. Build it. Fold it.

Review games for Little Chute High School Biology, Essential Standard 1.4: Protein Structure and Function [HS-LS1-1].

> I can model how DNA structure determines the structure and function of proteins which carry out essential functions for all cells.

## What's inside

| Level | Target | Games |
|---|---|---|
| 1 · Vocabulary Corral | I can define transcription and translation. | Don't Fry the Egg, Crossword, Acrostic Puzzle, Define It |
| 2 · Diagram Arena | Additionally, I can model or interpret the processes of transcription and translation. | Label: Transcription, Label: Translation, Pin the Tail on the Mustang, Transcription or Translation? |
| 3 · Protein Ranch | Additionally, I can explain protein folding, and model different protein structures and shapes to explain the role of a resulting protein in a living organism. | Codon Wheel Protein Builder, Structure Check, Enigma Decoder, Dogma Invaders |

My Evidence lets students write a Self-Directed Learner reflection and download a PDF or PNG. They can turn it in on Google Classroom or add it to their portfolio.

## Files

- `index.html`: the whole app (HTML, CSS and JavaScript in one file)
- `favicon.svg`: browser tab icon (Mustang badge)
- `apple-touch-icon.png`: home-screen icon for phones and iPads

There are no build steps and no dependencies. The only outside resource is Google Fonts.

## Student progress

Scores, names and reflections are saved in each student's own browser (localStorage). Nothing is sent to a server. Students should use the same device and browser each time. Clearing browser data or using a private window starts them fresh.

## Updating

Replace `index.html` in this repository (on GitHub: open the file, then use the pencil icon, or "Add file" and then "Upload files"). Vercel redeploys automatically within a minute of each commit.
